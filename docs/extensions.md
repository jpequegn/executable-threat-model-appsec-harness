# Extension paths

## Practical extensions

1. Add more owned synthetic services for IDOR, local-only SSRF, secret canaries, artifact
   provenance, and stateful approval workflows.
2. Add model adapters behind the existing discovery and verifier contracts. Route the two lanes
   to different providers and retain deterministic reference graders.
3. Generate threat-model diffs from architecture changes and rerun only affected invariants.
4. Export minimized failed cases to a general agent replay system and promote confirmed fixes into
   CI regression suites.
5. Add OpenTelemetry spans whose payload policy permits digests and reason codes but denies raw
   prompts, secrets, and exploit material.

## Innovative uses

- **MCP capability assurance:** model an MCP server's resources and tools as assets and entry
  points, then verify confused-deputy and indirect-prompt paths using synthetic hosts.
- **Security-agent promotion tests:** require a candidate security model to improve verified
  findings per reviewer hour without increasing false containment or regression rates.
- **Executable architecture review:** turn every approved trust-boundary change into a versioned
  diff, affected-eval plan, and signed assurance packet.
- **Patch-bandwidth scheduling:** optimize which verified findings enter remediation under a fixed
  reviewer-time budget while preserving explicit deferral risk.
- **Defensive deception evaluation:** add local honeytokens and measure whether discovery identifies
  synthetic reconnaissance without leaking the canary into evidence.
- **Cross-family verification:** deliberately use unrelated model families for discovery and proof,
  then measure correlated-error reduction across repeated trials.
